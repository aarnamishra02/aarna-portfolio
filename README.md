# Form & Story — Aarna Mishra Portfolio

A product designer's portfolio for the UI/UX Design Principles assignment.

## Preview
Open `index.html` in a browser. No build step or dependencies are needed.

## Assignment features
- About Me, Portfolio and Contact sections in semantic HTML.
- A cohesive cream, burnt orange, lilac and forest-green palette; expressive, responsive typography.
- CSS Grid and Flexbox with explicit mobile (768px), tablet (1024px) and desktop (1025px) breakpoints.
- Hover transitions, project-card entry animations and reduced-motion support.
- Three project-detail modals using native dialog, Escape, focus trapping and focus restoration.
- Navigation tooltips on hover and keyboard focus; Escape dismisses them.
- Labelled contact fields, local validation, helpful errors and status feedback.
- Keyboard focus styles, a skip link and accessible descriptions for the CSS-drawn thumbnails.

The projects and designer profile are fictional demonstration content. The contact form validates locally; it does not send or store messages.
